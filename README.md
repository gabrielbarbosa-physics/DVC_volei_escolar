# DVC_volei_escolar
Projeto completo do web app do Drummond Voleibol Clube.
O arquivo "db_modelo_logico" contém o arquivo .html contendo todas
as informações referentes ao modelo lógico do banco de dados. 
execute em um navegador para vizualização completa.

O arquivo "db_modelo_físico" contém a implementação do banco;
até o presente momento, integramos somente a carteirinha.

o arquivo manager.py (a construir) contém a API baseada em
(Py) Flask.
